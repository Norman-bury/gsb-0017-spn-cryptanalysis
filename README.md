# 差分密码分析（简化 SPN）

目录里有一个编译好的本地加密程序 `oracle`，背后是一个 3 轮简化 SPN 分组密码。S 盒、P 置换、密钥调度都是公开的，写在下面。唯一隐藏的是 32 位主密钥的值，你的任务是用差分密码分析把它恢复出来，不能穷举。

## oracle 怎么用

`oracle` 是 arm64 可执行文件。从 stdin 读 16 位明文，每行 4 个十六进制字符，逐行输出对应密文，也是 4 个十六进制字符。

```bash
printf '0000\n1234\nffff\n' | ./oracle
```

一次喂多少行都行，它会把每行当做一个明文加密。恢复密钥需要 2 的 16 次方对选择明文，也就是 13 万多行，用管道一次喂进去很快。

## 密码规格（全部公开）

16 位分组，4 个 4 位半字节。半字节从高位到低位编号 0 到 3。

S 盒是 4 位到 4 位的置换，输入 x 映射到 `SBOX[x]`：

```
SBOX = [0xE,0x4,0xD,0x1,0x2,0xF,0xB,0x8,0x3,0xA,0x6,0xC,0x5,0x9,0x0,0x7]
```

对 16 位值做 S 就是四个半字节各自过一遍 S 盒。P 置换是 4 乘 4 的位转置，把第 k 个半字节的第 b 位搬到第 b 个半字节的第 k 位，按位理解就是下面这段，P 是对合，P 再 P 一次回到原值：

```python
def P(x):
    nib = [(x>>12)&0xF, (x>>8)&0xF, (x>>4)&0xF, x&0xF]
    out = 0
    for j in range(4):
        on = 0
        for k in range(4):
            on = (on << 1) | ((nib[k] >> (3-j)) & 1)
        out = (out << 4) | on
    return out
```

加密是 3 轮，每轮先跟轮密钥异或、过 S 盒、过 P 置换，最后再跟末轮白化密钥异或：

```
x0 = 明文
x_{r+1} = P(S(x_r XOR K_r))   r = 0,1,2
密文 = x_3 XOR K_3
```

密钥调度：32 位主密钥 M = hi || lo，hi 是高 16 位，lo 是低 16 位。四个轮密钥为：

```
K0 = hi
K1 = lo
K2 = (hi + lo) mod 2^16
K3 = (hi + 2*lo) mod 2^16
```

## 你要交付什么

写一个 `solve.py`，跑起来后调用 `./oracle` 恢复出 32 位主密钥，把密钥打到标准输出（8 个十六进制字符），同时在本目录生成一份 `report.md`。

报告必须包含三样东西，用来证明你是靠差分统计恢复的而不是穷举：

- S 盒的差分分布表（DDT），至少要有完整表或关键行。
- 你选的差分特征和它的概率，包括末轮恢复用哪条、剥完末轮后逐半字节用哪几条。
- 候选密钥的命中统计，每个恢复的半字节列出真密钥候选和次高候选的命中数。

## 判分标准（`grade.py`）

```bash
python3 grade.py
```

`grade.py` 会跑 `python3 solve.py`，限时 10 分钟，检查三件事：

- 恢复出的密钥等于隐藏的主密钥，错一个半字节都不算过。
- `report.md` 存在且包含差分分布表、差分特征及概率、候选命中统计。
- 全程没有穷举主密钥（报告里的 DDT 和命中统计就是证据，缺了直接判不过）。

三件事都过了输出 `PASS`，退出码 0；任何一处不过输出 `FAIL`，退出码非 0。

## 约束

- 本地离线，只许用标准库。`./oracle` 只能拿来加密，不能反汇编去抠密钥。
- 10 分钟内完成。2 的 16 次方对选择明文足够，差分特征选对、命中计数阈值定对就能恢复。
- 关键是自己从 S 盒算出 DDT、沿着 P 追差分特征、做末轮密钥恢复，哪一步错了都恢复不出来。
